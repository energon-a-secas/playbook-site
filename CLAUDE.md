# CLAUDE.md: Playbook

Playbook: bilingual career advice for tech workers, ES/EN with series navigation (playbook.neorgon.com)

**Live:** playbook.neorgon.com · **Port:** 8819

## Run

```bash
make serve
```

Then open http://localhost:8819. It must be served over HTTP. The app is ES modules, and `file://` blocks them.

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
- `js/app.js` is 54 lines against a 50-line guideline; it should be an entry point, not a module.

## Gotchas

- Reduced motion sets `transition: none` on every element (`css/style.css`, the fleet rule of 2026-10-16), so `transitionend` never fires for a visitor who asked for it. Code that waits on that event to remove or reveal something needs a timer fallback. This is why the old local `toast()`, which removed its element only on `transitionend`, was deleted rather than kept: it had no callers. For a toast, re-export `showToast` from `./neorgon-dom.js` the way `escHtml` is; it hides on a timer, and the `.toast` / `.toast.visible` styles already match it.
